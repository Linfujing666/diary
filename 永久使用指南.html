🌿 永久使用指南

富婆的财富日记 · 变成桌面 App + 数据永久保存
全程免费 · 大约 30 分钟搞定 · 只需做一次

📋 目录（共 5 步）
  1. 注册 GitHub 账号（5 分钟）
  2. 上传 App 文件，开启免费托管（10 分钟）
  3. 手机上安装成桌面 App（2 分钟）
  4. 开启云同步，数据永久保存（5 分钟）
  5. 换手机 / 数据丢失后怎么恢复（存好这页）
1

注册 GitHub 账号

GitHub 是全球最大的代码托管平台（微软旗下），我们的 App 文件和记账数据都会免费存在这里，永久、私有、不收费。

操作：

  1. 电脑或手机浏览器打开 github.com
  2. 点 Sign up，填邮箱、设置密码
  3. 邮箱收到验证码，输入验证
  4. 用户名随便起（比如 fufuluojia123），这个用户名后面会用到
💡 记住你的用户名和密码，这是整套方案唯一的"钥匙"。建议把密码记在备忘录或密码管理器里。
2

上传 App 文件，开启免费托管

把「富婆的财富日记」的文件传到 GitHub，开启 GitHub Pages，就会得到一个永久免费的网址，比如：

https://你的用户名.github.io/diary/

2.1 创建仓库

  1. 登录 GitHub，点右上角 ＋ → New repository
  2. Repository name 填：diary（就用这个名字，别的不用管）
  3. 选 Public（免费账户只有公开仓库能开 Pages）
  4. 勾选 Add a README file
  5. 点绿色按钮 Create repository

2.2 上传文件

  1. 进入刚创建的 diary 仓库页面
  2. 点 Add file → Upload files
  3. 把解压后的 App 文件全部（index.html、style.css、app.js、data.js、pages.js、mascot.js、sw.js、manifest.json、所有 png 图片）直接拖进网页
  4. 等进度条走完，点绿色 Commit changes
⚠️ 注意：要上传的是解压 zip 后的文件本身，不是那个 zip 压缩包。文件比较多，分批拖也行，每次都要点 Commit changes 保存。

2.3 开启 GitHub Pages（关键一步）

  1. 仓库页面点 Settings（设置）
  2. 左侧菜单找 Pages（在 Code and automation 分组里）
  3. 「Build and deployment」下的 Source 选 Deploy from a branch
  4. Branch 选 main，文件夹选 / (root)，点 Save
  5. 等 1～3 分钟，刷新页面，顶部会出现绿色提示，显示你的网址
💡 用手机浏览器打开这个网址测试一下，能看到记账界面就成功了！建议把这个网址收藏，或者发到微信"文件传输助手"里存着。
⚠️ 国内访问慢怎么办？GitHub Pages 在国内偶尔加载慢。可以先忍忍（App 安装后有离线缓存，之后打开很快）；实在不行，以后可以迁移到 Cloudflare Pages（同样免费，国内更快），需要的时候再找人帮忙迁。
3

手机上安装成桌面 App

用手机浏览器打开你的网址，然后"添加到主屏幕"，它就会变成一个真正的桌面图标，全屏运行、没有浏览器地址栏，和普通 App 一模一样。

📱 iPhone（Safari）

  1. 用 Safari 打开你的网址（必须是 Safari，微信/Chrome 里不行）
  2. 点底部工具栏的 分享按钮（方框里有个向上箭头 ⬆️）
  3. 往下滑，找到并点 「添加到主屏幕」
  4. 名称可以改成「财富日记」，点右上角 「添加」

🤖 Android（Chrome / 系统浏览器）

  1. 用 Chrome 打开你的网址
  2. 点右上角 ⋮（三个点菜单）
  3. 点 「添加到主屏幕」 或 「安装应用」
  4. 确认添加
💡 安装后桌面会出现一个绿色小钱包🌿图标，点开就是全屏 App。以后记账都从这个图标进，不要再从浏览器进了（两边数据是分开的！）。
4

开启云同步，数据永久保存

装好 App 后，数据默认只存在这台手机里——手机丢了、App 删了、清了缓存，数据就没了。开启云同步后，每次记账都会自动备份到 GitHub，永久保存。

4.1 生成 GitHub Token（云同步的钥匙）

  1. 电脑浏览器登录 GitHub，点右上角头像 → Settings
  2. 左侧最底部 Developer settings
  3. Personal access tokens → Tokens (classic) → Generate new token (classic)
  4. Note 随便填（如 记账备份）；Expiration 选 No expiration（永不过期）
  5. 权限列表里只勾选 gist 这一项
  6. 点底部绿色 Generate token
  7. 立刻复制生成的 ghp_ 开头的一长串字符（只显示这一次！）
🚨 三个坑，务必注意：
① 必须用 classic 版 Token（Fine-grained 那种不支持 Gist）
② 必须勾选 gist 权限，别的都不用勾
③ Token 生成后马上复制保存，关掉页面就再也看不到了

4.2 在 App 里配置

  1. 打开财富日记 App → 左侧导航 → 设置
  2. 点 云同步（☁️ 那一项）
  3. Token 栏粘贴刚才的 ghp_...
  4. 勾选 「开启自动同步」
  5. 点 ☁️ 立即上传（第一次备份），提示"已上传到云端"就成功了
💡 开启后，每次记账（间隔 10 分钟以上）会自动上传。设置页会显示"上次同步时间"，可以随时确认。也建议每个月手动点一次「立即上传」图个安心。
⚠️ Token 也要存好！建议和 GitHub 密码放在一起（备忘录/密码管理器）。忘了也没关系——重新生成一个，在 App 里替换掉旧的就行，数据不受影响。
5

换手机 / 数据丢失后怎么恢复

只要 GitHub 账号和 Token 还在，一切都能找回来。整件事的原理：

☁️数据备份存在 GitHub Gist（永久）
⬇️
📱新手机打开网址 → 装到桌面
⬇️
⚙️设置 → 云同步 → 填 Token
⬇️
📥点「从云端恢复」→ 自动找回全部数据

详细步骤：

  1. 新手机浏览器（iPhone 用 Safari / Android 用 Chrome）打开你的 GitHub Pages 网址
  2. 按第 3 步的方法添加到桌面
  3. 打开 App → 设置 → 云同步
  4. Token 栏填原来的那个 ghp_...（Gist ID 留空不用管）
  5. 点 📥 从云端恢复（旧手机迁移）
  6. App 会自动在云端找到你的备份，提示"已从云端恢复"，所有账目、分类、购物记录全都回来了
  7. 记得重新勾选自动同步
💡 这套流程同样适用于：手机掉了、误删 App、清了浏览器数据、App 出问题想重来——只要 GitHub 里的备份在，就什么都不怕。

❓ 常见问题

数据到底存在哪？安全吗？会被别人看到吗？
三份拷贝：① 手机本地（日常秒开）② GitHub Gist 云端备份（私有，只有持有你 Token 的人能看，不输入 Token 连你自己都看不到）③ GitHub Pages 上的只是 App 程序文件，不含你的数据。GitHub 是微软旗下、全球最大代码平台，可靠性远超任何网盘。
GitHub 免费吗？会不会哪天收费/倒闭？
GitHub Pages 和 Gist 对个人免费且无容量焦虑（记账数据每年才几百 KB）。GitHub 成立于 2008 年，2018 年被微软收购，是行业基础设施级的存在。真有万一，你的数据也能随时导出 JSON 文件带走（设置 → 导出数据）。
为什么必须上传到 GitHub，不能直接用文件夹里的 index.html？
PWA（桌面 App + 离线缓存）要求网页通过 HTTPS 网址访问，直接打开本地文件这些功能全部失效。GitHub Pages 提供的就是免费 HTTPS 网址。
以后 App 更新了怎么办？
把新文件按第 2.2 步的方法拖进 GitHub 仓库（会提示覆盖，确认即可），手机上关掉 App 重开，1～2 秒后自动更新到新版。
换了手机，但 GitHub 密码也忘了？
先去 github.com 用注册邮箱找回密码（点 Sign in → Forgot password）。密码找回来，一切都能救。所以：注册邮箱必须是自己常用、不会丢的邮箱。
能多台设备同时用吗？
可以，每台都按第 5 步配置云同步。但注意：云同步以"最后一次上传"为准，建议只在主力手机上开自动同步，其他设备手动点「从云端恢复」再操作，避免互相覆盖。
